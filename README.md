# Randi Maulana — Portfolio

Personal software engineering portfolio and project showcase built with Next.js 16 (App Router), React 19, TypeScript, Three.js, and Tailwind CSS.

## Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Library:** React 19
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS v4
- **3D & Canvas:** Three.js (Native WebGL & THREE.Timer)
- **Animations:** Framer Motion
- **Form & Validation:** React Server Actions, Zod, Resend
- **State Management:** Zustand 5

## Getting Started

### 1. Clone & Install Dependencies

```bash
git clone https://github.com/Jejekdf/portofolio.git
cd portofolio
npm install
```

### 2. Configure Environment Variables

Create a `.env.local` file in the root directory:

```env
RESEND_API_KEY=your_resend_api_key
CONTACT_TO_EMAIL=maulanarandi531@gmail.com
```

### 3. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production

```bash
npm run build
npm run start
```
